# 🍬 Sweet Management System

## 📘 Overview

Sweet Management System is a software solution designed to support and optimize operations for sweets shops. Built as a Software Engineering course project by Computer Engineering students at **NNU University**, it follows Agile principles with a focus on **Test-Driven Development (TDD)** and clean software architecture.

The system aims to enhance business productivity by streamlining product management, inventory, and sales workflows.

---

## ⚙️ Features

- 🧾 **Product Management**: Add, edit, and delete sweet items with details like price, category, and availability.
- 📦 **Inventory Tracking**: Monitor ingredients and supplies to prevent shortages and overstock.
- 💰 **Sales System**: Simulate customer purchases and track revenue generation.
- 🧑‍💼 **User Roles**: Support for admin and staff roles with different privileges.
- 📊 **Reporting Dashboard**: Basic analytics for sales and inventory levels.
- ✅ **TDD Workflow**: Developed using unit tests and incremental development cycles.

---

## 🛠️ Technologies Used

- **Language**: Java
- **Database**: PostgreSQL or MySQL (depending on group)
- **Frameworks**: JUnit (for testing)
- **Development Tools**: IntelliJ IDEA / VS Code / NetBeans
- **Version Control**: Git & GitHub
